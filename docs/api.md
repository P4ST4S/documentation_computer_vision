# API

## Point D'Entrée D'Inférence

`POST /predict`

Accepte une image d'aliment et retourne une segmentation ainsi qu'une estimation calorique.

## Vérification D'État

`GET /health`

Retourne l'état du service et la disponibilité du modèle.
